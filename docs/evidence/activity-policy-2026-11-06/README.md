# Local activity-policy and maintenance evidence

Captured from actual React/Express/Auth/Firestore emulator flows. All identities,
work orders, activities and facilities notes are synthetic test data.

- `activity-policy-form.png`: optional end/seat/deadline/facilities inputs and
  review summary in campus time.
- `activity-linked-maintenance.png`: a trusted demo work-order association and
  status projected through the actual receiver. The disabled-environment notice
  is intentional: the browser stack makes no real partner requests.
- `activity-deadline-mobile.png`: Student registration disabled after its deadline,
  without exposure of private facilities notes or work-order metadata.
- `check-results.json`: final build, backend and browser results and limitations.

No real maintenance request, production hookup, work-order assignment, new cloud
index, migration, code publication or lecturer approval is claimed. Raw operational
logs and browser traces remain outside this evidence folder.
