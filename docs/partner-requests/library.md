# Integration request — Library

Hi Library team! We’re Team 12, **Campus Events & Clubs**.

We’d like to connect with your system using **one existing API endpoint** to help students find useful resources related to a workshop or activity.

**Proposed connection:** Our backend makes a **GET** request to search your catalog by a topic or keyword, such as programming, entrepreneurship or language learning. We would show matching resources alongside the activity, with links to your library system.

Useful fields would be:

- Stable resource/book ID and title.
- Author, subject or short description.
- Catalog/details link.
- Availability, if your API already provides it.

**Does your current API support catalog search?** If not, could you offer a general resource list, subject categories or upcoming library events instead? Please tell us which existing endpoint you can provide so we can choose a useful connection. We do not need borrowing/reservation actions or private borrower histories for this first flow.

Please share the endpoint URL, HTTP method, authentication instructions, search parameters or pagination, and an example response. An HTTPS ngrok URL is fine for testing.

Please exchange credentials privately and let us know when your team is available for a coordinated test. Thanks!
