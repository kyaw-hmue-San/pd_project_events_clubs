# Integration request — Internship

Hi Internship team! We’re Team 12, **Campus Events & Clubs**.

We’d like to connect with your system using **one existing API endpoint** to help students discover career-related activities.

**Proposed connection:** Our backend makes a **GET** request for upcoming career workshops, employer talks or internship information sessions. We would show suitable results in our activity discovery experience, with links back to your system.

Useful fields would be:

- Stable event ID and title.
- Short description and organizer/company.
- Date/time, location and details or registration link.
- Published/available status, if supported.

**Do you already provide this information through an API?** If not, could you offer a read-only endpoint for open internship opportunities, participating companies or application deadlines instead? Please tell us what your current API can provide so we can agree on one useful connection. We are not requesting student applications, CVs or private applicant records.

Please share the endpoint URL, HTTP method, authentication instructions, supported filters or pagination, and an example response. An HTTPS ngrok URL is fine for testing.

Please exchange credentials privately and let us know when your team is available for a coordinated test. Thanks!
